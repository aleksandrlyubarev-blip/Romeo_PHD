# Сравнение статей 2009 → 2014 → 2021 и извлечение эталонов для RWDM-моделирования

Дата: 2026-07-26. Ветка: `claude/article-comparison-2009-2014-vdmuzh`.

Документ сверяет три работы по переносу спиновой поляризации ⁸Li→⁶Li в LiF
(система, лежащая в основе диссертации и бенчмарка `docs/quantum-benchmark-rwdm-lif.md`),
фиксирует, что нового даёт каждая, и выносит проверяемые константы/формулы как
эталонный набор для валидации кода RWDM-baseline.

## 1. Что нового в каждой работе (эволюция)

### 2009 → базовая линия
- Единое поле **200 Гс**, ориентация **[111]‖H₀** (кроме Рис. 5: 200/1210 Гс, [100]/[111]).
- Полуфеноменологическая `p(t) = F(t)·G(t)`, где `G(t)` — **простая** трёхпараметрическая
  поправка (ур. 7), 2 подгоночных: `b₁, b₂`.
- **Таблица 1** — готовые константы для 4 образцов (см. §2).
- Диапазон данных `β₀t ≤ ~15` (упомянуто в 2014 как предел прежних измерений [1,3]).
- Уже сформулированы три стадии: короткие времена (`p=1−cz_e ν₀t`, ненаблюдаемо),
  промежуточные (`exp(−(β₁t/(ξ+1))^{1/2})`, `β₀t≲5`), диффузионная асимптотика
  (`p∼(β₀t)^{−3/2}`, `β₀t≳20`).

### 2014 → главный шаг твоей диссертации: полевая зависимость + уточнённая G
Что добавлено относительно 2009:
1. **Управление скоростью процесса магнитным полем** — три поля 200/691/1200 Гс
   при трёх концентрациях. Именно полевая зависимость отделяет вклад корреляций
   локальных полей от диффузионного тензора.
2. **Новая, гораздо более гибкая форма `G(β₀t)`** (ур. 12): добавлены член `(b₀x)^{1/2}`
   и коэффициент `b₁`, плюс логнормальный «горб» `c₁·exp(...)`. Это качественно
   отличает её от ур. (22) в [20] и от простой формы 2009 г. Коэффициент линейного
   члена изменился **0.125 → 0.138**.
3. **Уточнение шкалы β₀**: введено `β₀G` (значение при гауссовой аппроксимации
   CR-формы) и поправка `β₀ = 1.122·β₀G` (ур. 13) за счёт негауссовости линии и
   корреляций локальных полей. **Это ключевой численный сдвиг относительно 2009**
   (см. §3).
4. Диапазон расширен до **`β₀t ≈ 50`**, вошла область перехода к диффузии.
5. Впервые — прямое сопоставление с оптическим фёрстеровским переносом экситонов
   (методы: деполяризация флуоресценции, нестационарная лазерная спектроскопия,
   four-wave mixing) и критика анализа [10], игнорирующего `ln(1/Φ)≤const·t^{1/2}`
   в неупорядоченной среде.
6. **Количественная формулировка «превышения» (outlier)**: амплитуда
   `max(P₀₀−P_diff)/P_diff` оказалась **вдвое больше** предсказанной ур. (9), и
   предасимптотическая стадия длинная. ← прямой мост к открытому вопросу бенчмарка.

### 2021 → обзор + ранее не публиковавшаяся теория диффузии ядер
Новое относительно 2009/2014 (по маркерам «unpublished up to now»):
- **Разд. 5** — полный аналитический вывод влияния **трансляционной (тепловой)
  диффузии атомов Li** (хоппинг κ~1 с⁻¹ при повышенных T) на перенос. В 2009/2014
  этого эффекта нет вообще (там T=const, статический беспорядок). Раньше публиковался
  лишь результат `M₁(λ)=1.679 c(w₀κ³)^{1/4}/λ²` [31,34,38] — вывод (ур. 67–92) впервые.
- Обобщение по дальнодействию: для `v(r)∼r^{−s}`, `s≥6`,
  `M₁(λ,D→0)∼λ^{−σ}`, `σ=(7s−10)/(2(s+2))`; для диполя s=6 → σ=2.
- Систематизация мультиспиновых/мультиквантовых резонансов (итерация Арнольда,
  семейство из девяти трёхспиновых резонансов). Для RWDM-baseline второстепенно.
- **Внимание:** обзор 2021 НЕ воспроизводит формулу `F(t)·G(t)` — она остаётся в
  2009 (ур. 6–7) и 2014 (ур. 9,11,12). Первоисточник поправки G для кода — 2014.

## 3. Расхождения между статьями — что перепроверить в коде

**(A) β₀ 2009 vs 2014 — сдвиг шкалы на +12.2%.**
То, что 2009 называет `β₀` (10.80 с⁻¹ при c=10.06%), совпадает с тем, что 2014
называет `β₀G` (10.83, гауссова аппроксимация). 2014 уточняет: реальная
`β₀ = 1.122·β₀G = 12.15 с⁻¹`. Множитель 1.122 — вклад негауссовости CR-линии и
корреляций локальных полей.
→ **Следствие для бенчмарка:** окно `β₀t=30–108` из `quantum-benchmark-rwdm-lif.md`
зависит от того, какая нормировка β₀ зашита. При переходе 10.80→12.15 то же
физическое время сдвигает `β₀t` в **1.122 раза**. Зафиксировать в коде, какая β₀
используется, и по возможности перейти на уточнённую 2014.

**(B) β₁/β₀ при 200 Гс: 0.9426 (2009) vs 0.917 (2014).**
Твой doc использует 0.9425 (значение 2009). 2014 даёт 0.917. Расхождение ~2.7% —
из-за той же поправки 1.122 (β₁ и β₀ корректируются разными множителями).
Решить, какое значение канонично для текущих расчётов.

**(C) Коэффициент линейного члена G: 0.125 (2009, ур. 7) → 0.138 (2014, ур. 12).**
При замене формы G нужно менять и его.

**(D) Внутренняя опечатка в 2009.** На стр. 412 `β₀≈40c²ν₀`, на стр. 413
`β₀=(512/243)π³c²ν₀=65.3c²ν₀` — расходятся в 1.63×. Правильна форма 65.3
(подтверждена выводом 2014, п. §2.3). «≈40» — грубая/ошибочная. Подпись к Рис. 1
2009 (`ν₀=10.8 с⁻¹`) подозрительно равна β₀ образца 4 — вероятна опечатка.
(Мелочь парсинга: «c⁻¹» в Таблице 1 — кириллическая «с»=секунда, не 1/концентрация.)

## 4. Две формы G(β₀t) — что использовать

**2009, ур. (7)** — простая, 2 параметра:
```
G(t) = 1 − [ (0.125+α)·β₁t − b₁·(β₁t)² ] / (1 + b₂·β₀t)³
```

**2014, ур. (12)** — расширенная, параметры на каждую пару (c, H₀) из Таблицы:
```
G(x) = 1
  − [ −b₀·x^{1/2} + (0.138+b₁)·x − d₀·x^{3/2} − d₁·x² ] / (1 + f₀·x^{1/2} + f₁·x + f₂·x^{3/2})²
  + c₁·exp( −½·[ ( ln(x²+h²) − ln(a₁²+h²) ) / ln b ]² )
где  x=β₀t,  d₁=1,  h=0.1;  a₁,b,c₁,d₀,f₀,f₁,f₂,b₀,b₁ — из Таблицы 2014.
```
Обе НЕ описывают `(1+ξ)w₀t < 1` (там зависимость линейна). Для полевой зависимости
и для области `β₀t` до ~50 канонична форма 2014; форма 2009 — только 200 Гс.

## 5. Что это даёт моделированию (связь с `quantum-benchmark-rwdm-lif.md`)

1. **Открытый вопрос бенчмарка = «outlier» из 2014.** Твой doc фиксирует расхождение
   прямого суперячеечного расчёта с `F(t)·G(t)` в окне `β₀t=30–108`. В 2014 это
   названо явно: реальное превышение `max(P₀₀−P_diff)/P_diff` ~**вдвое больше**
   предсказания ур. (9), предасимптотика длинная. То есть расхождение — не баг кода,
   а известный недоучёт полуфеноменологической формулы; открытый вопрос — объясняет
   ли его полная квантовая динамика (Tier B/C бенчмарка).
2. **Нормировка β₀ — критична для окна.** Использовать уточнённую `β₀=1.122·β₀G`
   (2014), а не «сырую» гауссову 10.80 (2009), иначе окно `β₀t` смещено на 12%.
3. **Golden-набор для тестов** (§2): ξ=3, g-факторы, μβ₀τ=5.11, φ=2.09, `β₀∝c²`
   (K≈1067), β₀G(c) три значения, β₁/β₀ по трём полям. Зашить как эталоны
   Fortran/Python-эквивалентности (упомянута в §1 doc бенчмарка).
4. **σ-критерий (2021)** `σ=(7s−10)/(2(s+2))`: для диполя s=6 длинновременная
   `M₁(t)∼t`; подсказывает, легитимно ли ориентационное усреднение и в каком
   асимптотическом режиме суперячейка.
5. **Полевой рычаг (2014)**: три поля 200/691/1200 Гс дают три разных β₁/β₀
   (0.917/0.387/0.084) при той же геометрии — независимая проверка кода:
   меняя только зеемановскую расстройку узла 0 (tier B1), воспроизвести три
   кривые одним инстансом беспорядка.
